# Infant Mortality Research – Econometrics Sample

## About
This repository contains a sample R script from my ongoing academic research on the determinants of infant mortality in Brazil.  
The goal is to demonstrate applied econometric skills, including data cleaning, regression analysis with robust standard errors, and visualization.  

## Methods
- **Regression Analysis (OLS)** with robust standard errors (HC1).  
- **Clustering** and basic data simulation for demonstration.  
- **Visualization** with `ggplot2` to explore relationships between variables.  

## How to Run
1. Clone or download the repository.  
2. Open the file `infant_mortality_analysis.R` in R or RStudio.
